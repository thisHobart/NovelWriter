## 2. 发现的问题及根因

1. **GUI 入口回归**：基线完整套件为 456 通过、1 失败。`main.py` 在 UI 迁移时移除了兼容调用方依赖的 `sys` 和 `run_gui` 间接层。
2. **评审 schema 静默补分**：缺失评分维度曾默认成 3.0，截断 JSON 可能被当作真实判决。现在完整字段先校验，仅允许一次受限 schema 修复。
3. **无证据低分会遮蔽有效硬伤**：真实盲读修复稿同时包含有效 `CHARACTER_LOGIC_BREAK` 和几个没有真实引文的低分。旧逻辑丢弃整份评审。现在首轮仍要求修 schema；第二轮仅撤销无依据分数的阻断权，保留有引文、影响和最小改法的硬伤。
4. **硬失败意见不可执行**：过去允许硬失败缺少真实引文、具体后果或最小修复。现在三项均为必填且引文必须存在于待审正文。
5. **故事圣经揭示期限没有进入生成边界**：第一章真实基线提前说出门内离开按钮机制。根因是 `must_not_reveal_before` 没有自动投影到章节契约。现在生成前自动填充 `withheld_truth_ids` 和 `reader_must_not_know_yet`，旧契约无需迁移。
6. **空结构字段覆盖已有揭示期限**：结构契约同 ID 记录的空字符串擦除了案件底稿中的 `chapter_2/chapter_3`。合并逻辑现在只让有意义的作者值覆盖已有值。
7. **每章机械强迫反转、攻防、道德两难和个人代价**：章节契约明确留空时，评审仍会因缺少这些节拍扣分甚至触发 schema 重试。现在完整 schema 仍必须返回，但契约声明为不适用的维度退出平均分和重试要求，并在 `reviewer_warning` 中记录 N/A。
8. **三路合并丢失软失败性质**：盲读仅差 0.06 分、无硬失败且必要维度达标，但合并平均分被其他评审拉高后 `soft_failure` 反而失真，导致无法按生产规则差分放行。合并结果现在保留各分评审的真实 shortfall；硬失败永不豁免。
9. **证物自毁后继续核心推理**：固定基线写出碎盘后恢复完整录像。现实审阅以真引文阻断，并定向改为销毁前已封存、可校验的独立审计副本。
10. **嫌疑人“主动送答案”**：第二章真实稿让方屿主动报出精确维护窗口，缺乏合理博弈。盲读引用原文并要求改为被动失言；定向修订后通过。
11. **供述过快和程序主体错误**：第三章初稿一问即招，并把侦查阶段技术工作交给检察机关。盲读和现实审阅分别阻断，修订为先抗辩后被物理事实卡住，并改由刑侦技术部门委托鉴定机构。
12. **身体反应模板检测漏变体**：原规则只识别“喉咙发紧”等固定词，漏掉“喉头滚动、呼吸发紧、虚汗、嘴唇抽动、手指痉挛”。规则扩展后第三章检测为 6 次；语言修订降为 0。
13. **全文语言修订会在两个目标间摇摆**：第一候选消除了身体套语，却产生“封存箱已经带走后又去取”的连续性硬伤；第二次全文重写修了连续性，又重新引入 4 次身体套语。最终只在原文引文精确唯一、改法给出明确替换句时应用确定性单句补丁，再做三路复审，不继续消耗全文重写。
14. **成本上限无法续跑**：真实三章在第三章两场已生成后触及 24 次上限。现在相同输出目录可从已验收 ledger 和真实 trace 恢复，只补缺失审阅，不重生成场景。
15. **Windows 控制台编码**：`cp1252` 环境打印中文 JSON 会在运行成功后抛 `UnicodeEncodeError`。CLI 会检测 stdout 编码，非 UTF 环境输出 ASCII 转义 JSON；文件仍保留 UTF-8 中文。

## 4. 改造前后证据

### 证物现实性

基线硬伤：

> 方屿抢过硬盘砸在地上，盘片已经碎裂；技术员接上两根导线，几秒钟后便从碎片里恢复了完整录像。

阻断意见引用“恢复了完整录像”，说明核心推理依赖不存在的证据，并要求只替换证据来源。修订后：

> 技术员没有碰硬盘碎片，只隔着证物袋记录破损状态。苏澄调出21:00前已经导出、封存并登记校验摘要的独立审计副本。

### 信息边界

真实单章早期版本提前公开门内离开按钮机制。修复后第一章契约自动封存 T001/T002/T003，真实契约审阅明确确认未泄露方屿身份、坏盘证明边界和离开按钮机制。

### 嫌疑人行为逻辑

第三章初稿让方屿直接承认刷卡。盲读硬失败指出证据尚未闭合、技术负责人“一问即招”不可信。最终稿先让其提出工牌代管，再由工牌回到死者口袋和门禁物理距离卡住说法，随后才承认刷卡。

### 中文表达

语言收敛前第三章集中出现“呼吸发紧、喉头滚动、指节泛白、嘴唇抽动、虚汗、手指颤抖”等模板反应，确定性计数为 6。最终稿计数为 0，改以动作和停顿承载压力，例如：

> 方屿垂下双手，站在原地沉默了片刻。

最终连续性单句也由“去防磁柜取原始封存箱”改为：

> 带上你的工作日志，去楼下做补充证言记录。
