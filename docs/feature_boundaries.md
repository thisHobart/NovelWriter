# 两个功能的边界

更新日期：2026-11-18。

小说创作和短视频脚本是同一个软件里的两个功能，彼此不连接：一个功能的代码不引用另一个功能的代码，改其中一个时不需要动另一个。两者共用的东西放在共用层，共用层不认识任何一个功能。只有主窗把两个功能放在一起。

## 代码放在哪

| 属于 | 位置 |
|---|---|
| 小说创作 | 界面在 `core/gui/pages/novel/`（工作区、步骤栏、各阶段页面、参数读写、页面用到的服务）；生成与保存在 `core/generation/`、`agents/` 等 |
| 短视频脚本 | 界面在 `core/gui/pages/short_video/`；业务在 `core/short_video/` |
| 共用层 | `core/common/`（停止信号、项目文件锁、模型服务的地址和密钥、获取模型、测试连接）；`core/gui/` 下的主题、图标、后台任务、模型服务配置窗口、`widgets/` 里的通用控件，以及 `core/gui/feature.py`；`core/utils/` |
| 主窗 | `main.py`、`core/gui/app.py`、`core/gui/main_window.py` |

新代码先问一句：只有一个功能用？放进那个功能。两个功能都要用？放进共用层，而且写成不认识任何一个功能的样子。

## 主窗和功能之间约定了什么

主窗只通过 `core/gui/feature.py` 里列出的几件事和功能打交道：

- 功能告诉主窗：有没有任务在跑；切走或关窗前要不要先处理未保存的修改；状态栏点「停止」时停哪个任务；关窗时停掉所有任务；左侧要不要显示一栏（小说显示步骤栏，短视频不显示）。
- 主窗告诉功能：切回来了（回到上次的页面并刷新）；模型服务配置刚保存过。
- 功能可以让主窗：切到另一个功能（首页的「切换到短视频脚本」、短视频「项目设置」里的「返回小说创作」）；通知「模型服务配置已保存」。

主窗只从 `core/gui/pages/novel/workspace.py` 和 `core/gui/pages/short_video/workbench.py` 打开两个功能。短视频第一次打开时才建立。

## 后台任务和状态栏

- 小说有自己的一个任务通道；短视频有文字、图片、视频三个通道，都由短视频自己持有。
- 有任务在跑时不能切换功能，所以一个时刻只有当前功能会有任务。
- 状态栏是共用的：功能把任务的名称、对象、位置和是否正在停止交给状态栏显示，状态栏不读任何一个功能的任务细节。

## 模型服务

- 各服务商（第三方 API、DeepSeek 官方、千问官方）的接口地址、API 密钥和模型名两边共用，存在 `llm_settings.json` 的 `providers` 里。
- 用哪个服务商，两边各自记：小说记在作品参数里（左侧「模型服务」）；短视频记在自己的设置里（顶部「服务配置 → 生成模型配置」），不跟项目走。短视频第一次打开时沿用小说当时的选择，之后互不影响。
- 短视频的「校验模型配置」和「生图 API 配置」只属于短视频，存在同一个文件的 `review`、`image` 两节里，只由 `core/short_video/v2/service_settings.py` 读写和检查；共用层只负责读写整节，不检查内容。
- 任何一边保存了模型服务配置，两边显示的配置状态都会更新。

## 共用界面

两个功能共用的界面规则，代码在 `core/gui/theme.py`、`icons.py`、`task_runner.py`、`widgets/`。

**配色与尺寸**

| token | 值 | 用途 |
|---|---|---|
| `ink.900` / `ink.600` / `ink.400` | `#1C1B19` / `#6E6C67` / `#9A9792` | 主文字 / 次要文字 / 三级文字与禁用 |
| `line` / `line.strong` | `#E4E4E1` / `#D6D5D1` | 分隔线与卡片边框 / 次要按钮边框 |
| `rail` / `canvas` / `surface` | `#F4F3F0` / `#FFFFFF` / `#FAFAF8` | 左侧栏 / 卡片与编辑区 / 内容区与状态栏 |
| `accent` / `accent.tint` | `#2C4A7C` / `#EDF1F8` | 主按钮、当前步骤、生成中 / 聚焦光晕、选中行 |
| `success` / `warn` / `danger` | `#2F7D4F` / `#B4761D` / `#B3392F` | 语义色；浅底为语义色加透明度 |

间距用 4 的倍数；字号只用 11 / 12 / 13 / 16 / 19；控件高 32px；圆角 4px（卡片 6px）。界面字体 `Noto Sans SC`，标题与正文稿 `Source Serif 4`。强调色一屏不超过 3 处。图标用描边式 SVG，不用 emoji。

**主窗与状态栏**

- 小说左侧步骤栏固定 248px，短视频不显示；内容区为 64px 页头 + 主体 + 44px 状态栏；最小窗口 1200 × 760。
- 状态栏：空闲显示输出目录和上次保存时间；运行中显示动作、进度条、已用时和红色「停止」；参数未保存显示提醒；失败显示错误摘要和「查看日志」。
- 「停止」点击后变为「正在停止…」并禁用，直到任务真正退出。

**后台任务**

`TaskRunner` 用 `QThread` + 信号：`succeeded` / `failed` / `cancelled` / `finished` 都在主线程发出，进度走 `progress(str, float)`。运行时用 `disable=[...]` 禁用控件，按钮进入忙碌态（禁用、换文案、加转圈）。后台线程不得触碰任何控件。

**通用控件**

| 控件 | 默认 | 悬停 | 聚焦 | 禁用 |
|---|---|---|---|---|
| 主按钮 | accent 底、白字 | `#22406F` | 加 3px accent.tint 光晕 | `#B9C3D6`，文案换为忙碌文案 |
| 次按钮 | 白底、line.strong 边 | surface 底 | 同上 | ink.400 字、line 边 |
| 输入框 / 下拉框 | 白底、line 边 | line.strong 边 | accent 边 + 光晕 | surface 底、ink.400 字 |

数值框、下拉框和滑块不响应鼠标滚轮，滚轮只用于滚动页面和列表。

## 测试和守护

- 测试按功能分在 `tests/common/`、`tests/novel/`、`tests/short_video/`，可以只跑一个功能的测试，例如 `pytest tests/short_video -q`。
- `tests/common/test_feature_boundaries.py` 检查引用关系：两个功能互相引用、共用层引用了某个功能、主窗绕过入口直接引用功能内部，都会失败并列出是哪个文件引用了哪里。唯一的例外是会启动整个软件做验收的脚本（目前只有 `core/evaluation/lore_acceptance_probe.py`），可以打开主窗。
- `tests/common/test_app_shell.py` 用真实主窗检查切换功能、关窗、运行和停止任务，以及两边各自记住模型服务。
