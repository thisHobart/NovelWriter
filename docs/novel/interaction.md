# 小说创作：交互设计

日期：2026-11-25。本文说明小说各页面的按钮和状态。
整体结构见[架构设计](architecture.md)，调用与文件见[接口设计](interfaces.md)。
配色、控件、主窗、状态栏和后台任务等两个功能共用的规则见[两个功能的边界 · 共用界面](../feature_boundaries.md#共用界面)。

## 1. 工作区

左侧步骤栏依次是「工作流总览」「作品参数」「世界设定」「故事结构」「场景规划」「章节撰写」，底部是「运行后端」「模型服务」和「配置」。

| 阶段状态 | 图标 | 副文案 | 可点击 |
|---|---|---|---|
| 已完成 | 对勾 | `已完成` 或完成说明 | 是 |
| 部分完成 | 半环 | 缺什么，例如 `还缺第 23、24 章正文` | 是 |
| 阻塞 | 锁 | 阻塞原因原文，常驻显示 | 否，点击时状态栏提示原因 |
| 未开始 | 虚线圆 | `未开始` | 是 |
| 运行中 | 转圈 | `进行中 · <当前子步骤>` | 是 |

状态以磁盘产物为准（见[架构设计](architecture.md#3-关键决定)）。小说只有一个后台任务通道，任务进度和「停止」都在底部状态栏。

## 2. 工作流总览

四个阶段各一张卡片，显示状态，可「单独运行」或「打开」。右栏：

| 控件 | 结果 |
|---|---|
| 运行完整流程 | 依次运行四个阶段 |
| 从断点继续 | 只运行未开始和部分完成的阶段；没有时提示「没有待继续的阶段。」 |
| 扫描已有成果 / 刷新 | 重新读取磁盘判定状态 |
| 分析当前内容 | 在状态栏显示各阶段文件数和正文累计字数，不调用模型 |
| 切换到短视频脚本 | 切到另一个功能 |

## 3. 作品参数

| 控件 | 结果 |
|---|---|
| 题材 | 重新填充子题材，子题材重置为第一项 |
| 子题材 | 重建右下附加设置页签（世界设定 / 角色 / 冲突）；未保存的填写会被清空 |
| 故事篇幅 | 重新填充可选的故事结构 |
| 质量闭环 | 只改变之后的生成行为，不触发生成 |
| 浏览… | 选择输出目录；取消不改动 |
| 保存参数 | 校验后写入 `system/parameters.txt`；出错的字段逐个标红，状态栏汇总，不弹窗 |
| 加载参数 | 有未保存修改时先确认 |
| 任意字段变更 | 状态栏显示「参数已修改，尚未保存」；下游已有产物时追加提醒，不删除任何产物 |

数值框和下拉框不响应鼠标滚轮。

### 生成前选择参数

界面有未保存修改、或界面与已保存参数不同时，任何生成入口先弹出选择：

| 选择 | 行为 |
|---|---|
| 保存并生成 | 校验并保存后启动；保存失败停在参数页，不调用模型 |
| 使用已保存参数 | 用磁盘版本运行，界面草稿保留；从未保存过参数时不可选 |
| 取消 | 不保存，不启动 |

模型服务不属于作品参数，始终用当前选择。

## 4. 世界设定

| 控件 | 结果 |
|---|---|
| 生成世界设定 | 依次生成势力、人物、世界观、主要人物背景和推荐标题 |
| 生成势力 / 生成人物 / 生成世界观 | 单步生成；已有产物时先确认覆盖。按钮自带完成标记和数量，如 `✓ 生成势力  6 个` |
| 完善主要人物 | 生成主要人物详细背景；需先有人物 |
| 推荐作品标题 | 生成候选标题 |
| 势力数量 / 人物数量 | 只影响下次生成，与作品参数一起保存 |
| 产物页签 | 势力、人物、人物关系、人物背景、名称与规则、候选标题、生成结果与草稿、待核对 |
| 编辑、查看 / 编辑 等入口 | 打开编辑窗口改世界观正文、人物和势力卡片、人物关系、人物背景、名称与规则登记表；保存不调用模型 |
| 打开参数检查记录 | 打开本作品的运行记录目录 |

**生成结果。** 每份产物最多初次生成加两次自动修复。规则没通过仍保存可读结果，显示「已生成，待修改」；检查服务出错显示「已生成，检查未完成」；只有完全没取得内容或保存失败才算任务失败。「生成结果与草稿」页可以：

- 「手动修改」或「编辑原始结构」：改当前保存的版本，或修好不可读的原始返回后「采用为当前设定」
- 「再修复一次」：只跑一轮修复和检查
- 「继续下一步」：用当前已保存的设定继续

**编辑与改名。** 编辑窗口绑定打开时的项目快照，关闭时可保存、放弃或取消；后台生成期间不能提交；文件被外部改过时不覆盖。人物、势力改名会同步结构化引用（关系两端、所属势力、登记表、背景文件），自由文本里的旧名不自动替换，列到「待核对」。核对完点「已核对当前版本」；再次修改会重新提示。当前不支持新增或删除人物、势力和关系。

## 5. 故事结构

| 控件 | 结果 |
|---|---|
| 生成故事结构 | 依次生成人物弧光、势力弧光、融入地点、详细情节 |
| 生成人物弧光 / 生成势力弧光 / 将地点融入故事弧 / 创建详细情节 | 单步生成 |
| 幕卡片 | 展开该幕全文 |

右栏「门禁」逐条列出下一阶段被阻塞的原因。

## 6. 场景规划

| 控件 | 结果 |
|---|---|
| 规划场景 | 生成章节大纲，再逐章规划场景 |
| 生成章节大纲 / 规划场景 | 单步生成 |

故事结构未通过时显示阻塞空态：标题说明缺什么，正文列出具体缺口，主按钮「前往故事结构」，另有「忽略门禁，强制规划」。强制规划不删除已有产物，生成的场景不标记为通过，阶段保持部分完成。

「输入依赖」面板说明门禁读的是磁盘产物，手动改文件后需要刷新。已验收章节的场景规划不再重新生成。

## 7. 章节撰写

| 控件 | 结果 |
|---|---|
| 撰写下一章 | 写第一个未写的章节；状态栏显示 `第 N 章 · 场景 i/j` 和停止 |
| 撰写全部剩余章节 | 连续写到最后；每章验收后立即保存；遇到被拦下的章节整轮停止 |
| 重写本章 | 已有正文时先确认 |
| 分析章节 | 只读分析，结果显示在右栏 |
| 章节列表 | 切换正文；生成中也可切换 |
| 停止 | 已保存的场景保留，未完成的章节标为部分完成 |

### 待复审

质量闸门拦下一章时，这一稿不进正式稿件，章节进入待复审：

| 位置 | 表现 |
|---|---|
| 章节列表 | 单列「待复审」，右侧写 `N 处硬伤` / `N 项未达标`；评审没给出结论时写 `评审未出结论` |
| 页头副标题 | `第 N 章待复审 · 已完成 M 章 · X 字` |
| 正文区 | 显示被拦下的这一稿，顶部横幅说明不在正式稿件里；被点名的句子标底色 |
| 右栏「复审」卡 | 卡在哪个评审、差多少分；问题按 硬伤 → 未达标维度 → 可选润色 排序，点一条滚到正文位置 |

| 控件 | 结果 |
|---|---|
| 照建议重修 | 只带勾选的条目重修，条目按引文分到所在场次；全部没勾时拒绝执行；仍不过则刷新清单 |
| 重跑评审 | 评审未出结论时替代「照建议重修」；只重判，不改正文 |
| 人工放行 | 先问理由；放行后验收照跑，理由记入账本 |
| 回去改规划 | 跳到场景规划 |

- 只写到一半就被拦下的章节没有完整正文，「照建议重修」和「人工放行」都不可用，只能「重写本章」。
- 问题出在场景规划本身时，复审卡注明规划里哪一句要改；勾选的条目全是规划问题时，「照建议重修」拒绝执行并说明去哪改。
