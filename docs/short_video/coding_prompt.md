# 短视频脚本模块维护编码 Prompt

文档版本：2.4；日期：2026-11-03。四工作区、生成循环和纯聊天会话拆分已实现；以下用于后续维护，不表示重新实施已完成改造。使用时另附本次具体需求。已完成情况与历史验证以 development.md 为准。

```text
依据 docs/short_video/ 下当前架构、接口、交互和开发文档，在已有实现上完成本次明确需求。
先检查现有代码、AGENTS.md 和未提交工作，保留已完成的文字提示词及左侧对话能力。

主界面只保留原文、改写、分镜、提示词四工作区，项目操作和导出统一收纳。
用户操作围绕内容：生成、直接编辑、继续、复制与导出。

生成与重新生成使用 Agent Loop：准备原始任务和上下文、生成候选、调用外部质量检查；通过即结束，未通过则在重试次数内继续。检查器独立于 Agent Loop，复用现有业务规则，不自行重新生成。
max_retries 默认 2，表示首次生成后最多再修改生成两次；0 时生成并检查一次即结束。
每次重试保留原始要求和必要上下文，加上最新候选与本次反馈；达到上限正常输出最新候选，不回退，不标成通过。
检查反馈仅本轮临时使用，不进入会话历史、问题清单、审核报告或运行请求原文；不新增存储。
模型／检查异常和取消不属于质量不通过，沿用现有异常与取消机制，不误触发质量重试。
所有依赖准备、格式修复、失败请求和复评受同一任务预算约束，保留有效候选与原稿。
合法候选在质量检查前落盘，暂不选为当前稿；提交时核对输入和当前版本，冲突只保留历史候选。
默认单阶段6次/300秒，分镜组合12次/600秒；资产组合按6×待生成项共享预算。
调用成功与检查通过分开记录，不能把 succeeded 当成 passed。
取消独立 AI 检查入口、人工检查记录和评分、逐项确认、人物绑定／重绑及目录确认。
不要只隐藏按钮而留下必须手动触发的检查或确认门槛。

人物、场景、道具关系在后台维护；普通保存做本地校验，不自动收费请求模型。
下一步先保存当前可见稿，再冻结真实来源启动下阶段；歧义只询问具体内容。
导出所选可用内容不要求用户确认所有视图或接受所有 warning。
保留左侧对话用于讨论，只发送用户输入与历史消息；不恢复引用／不引用按钮、文档附带或发送前自动保存，回复不写入稿件；不恢复作用目标、应用修改、聊天修订、按意见重新修订或另存当前编辑为候选入口。用户在右侧对应字段手动修改并保存。
ConversationStore 是唯一会话文件读写入口；conversation_context 是纯函数，负责规则、序列化和容量。
prepare 只读预检，execute 保存本轮用户消息后请求一次模型，再保存最终回复；不保存生成循环反馈。
默认48000字符，按最早完整轮次裁剪副本，本轮消息只加入一次；超长单条消息报错，磁盘历史不删。
聊天失败、取消、中断及没有完整回复的轮次不进入新请求；重试仅填回输入框，恢复不自动重发。
分镜先目录后分镜；资产设定生成后代码编译各视图，再编译镜头提示词，当前镜头优化才调用模型。

不增加人工审计、媒体 API 或预留空功能。根据本次变更选择 development.md 中必要的验证，
保留历史结果但不当作新需求已通过。验证真实主路径无检查、绑定或人工记录操作，
同时覆盖预算、取消、手改输入、保存冲突、恢复、导出和小说回归。
同步当前设计与实际结果；不自动提交、推送或发布。
```
