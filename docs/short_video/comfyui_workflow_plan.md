# ComfyUI 多工作流固定执行方案

日期：2026-11-15；版本：草案 3；状态：确认。

## 1. 本轮目标

通过粘贴固定的 API JSON 添加工作流，在生成界面选择工作流、上传图片并生成视频。继续使用现有媒体服务和 MCP 桥接执行固定流程，Agent harness 后续再确定。

本轮接入两套工作流：

| 工作流 | 图片输入 | UI 显示 |
|---|---|---|
| 现有 MiniMax H3 参考图工作流 | 固定 JSON 中接入生成链路的参考图片 | 参考图片 1～N |
| 新增首尾帧工作流 | 首帧图片、尾帧图片 | 首帧图片、尾帧图片 |

## 2. API JSON 加载与参数传递

1. 在配置窗口填写工作流名称，粘贴 API JSON 并保存。
2. 软件保存每套工作流的 JSON，通过工作流标识区分和选择。
3. 开发时适配这两套模板，识别其图片输入、提示词、必要参数和视频输出。
4. UI 根据选中模板显示对应控件，参数按节点要求的类型传给后端。
5. 后端上传图片，将返回的图片引用与用户参数写入本轮 JSON 副本，提交给 ComfyUI。
6. 获取生成结果，保存并在界面播放视频。

图片输入数量以固定 JSON 中实际接入生成链路的节点为准：三个有效图片输入显示三个位置，更新为四个后显示四个位置。首尾帧模板按已适配的输入关系显示“首帧”和“尾帧”。

新增图片节点在 ComfyUI 中连接完成后，重新粘贴 JSON。软件本轮只执行固定工作流，不在生成界面增加节点或修改连线。节点映射在模板适配中完成，日常配置只需填写名称和粘贴 JSON。

## 3. UI 手稿

继续使用“服务配置 → ComfyUI 工作流”和“提示词 → 镜头”两个现有入口。

配置窗口：

```text
┌──────────── ComfyUI 工作流配置 ────────────┐
│ 服务地址：[http://127.0.0.1:8188         ] │
│ 工作流：[H3 参考图 ▼]             [新增] │
│ 名称：[H3 参考图                       ] │
│ API JSON：                              │
│ ┌─────────────────────────────────────┐ │
│ │ 粘贴固定工作流的 API JSON           │ │
│ └─────────────────────────────────────┘ │
│                         [保存] [取消]   │
└─────────────────────────────────────────┘
```

生成视频区域：

```text
┌──────────────── 生成视频 ────────────────┐
│ 工作流：[H3 参考图／首尾帧 ▼]  [配置]   │
│                                         │
│ 参考图工作流：                          │
│ 参考图片 1：[选图] [缩略图]             │
│ ……按 JSON 中的有效输入数量显示……       │
│                                         │
│ 首尾帧工作流：                          │
│ 首帧图片：[选图] [缩略图]               │
│ 尾帧图片：[选图] [缩略图]               │
│                                         │
│ 提示词：[可编辑正文……]                 │
│ 参数：[当前工作流需要显示的参数]        │
│ [生成视频]   任务状态                   │
│ [视频播放区]                           │
│ [播放／暂停] [打开位置]                 │
└─────────────────────────────────────────┘
```

上图两种图片区域随选中的工作流切换，同一时间只显示对应的一种。参数控件使用模板适配时确定的名称、类型和默认值；已有任务继续沿用现有查询与结果获取入口。

## 4. 开发步骤

| 步骤 | 开发内容 | 主要文件 |
|---|---|---|
| 1 | 整理现有参考图与新增首尾帧两份固定 API JSON，确定图片、提示词、必要参数和视频输出 | [media_workflows.py](../../core/short_video/v2/media_workflows.py) |
| 2 | 将单工作流配置改为多工作流，支持名称、JSON 粘贴、保存与选择 | [media_workflows.py](../../core/short_video/v2/media_workflows.py)、[comfy_settings.py](../../core/gui/pages/short_video/comfy_settings.py) |
| 3 | 后端按所选模板接收参数，分别上传各输入图片，写入对应节点并提交；任务记录所属工作流与输入 | [media_service.py](../../core/short_video/v2/media_service.py)、[comfy_mcp.py](../../core/short_video/v2/comfy_mcp.py)、[media_repository.py](../../core/short_video/v2/media_repository.py) |
| 4 | 按手稿添加工作流选择与对应图片、参数控件，接入现有生成和播放流程 | [media_preview.py](../../core/gui/pages/short_video/media_preview.py)、[prompt_page.py](../../core/gui/pages/short_video/prompt_page.py) |
| 5 | 联调两套工作流，核对参数传递、图片对应关系和视频结果 | [test_comfyui_video.py](../../tests/test_comfyui_video.py) |

## 5. 开发验证

1. 从 UI 选择两套工作流，分别填写参数、选择图片并提交，核对后端收到的数据。
2. 核对提交给 ComfyUI 的节点值，确认参考图和首尾帧传入正确位置；更换 JSON 后图片输入数量同步更新。
3. 两套工作流分别生成视频，确认文件保存、UI 状态和播放正常。
