# 第二部分：网文视频推广工作台

文档版本：2.12；更新日期：2026-11-15。文字链路采用独立短视频忠实改编；ComfyUI 多工作流视频已实现，资产生图暂未接入。文字记录字段不迁移，媒体单独保存。

现有流程：原文 → 小说推文 → 视频推广文案 → 分镜 → 人物／场景／道具及镜头提示词 → 文字导出。

默认文字提示词升级为各阶段 default-v3：第一次整理原文中一个有因果与已有结果的事件，第二次转成可见动作、对白和必要旁白；不强制爆款、悬念、笑点或反转。允许忠实口语化与合理外化，不新增关键事实或结局。视频文案与分镜按少于60秒规划；素材缺结果时如实说明，不补造结局。兼容字段 cliffhanger 现在仅表示“结尾段”，旧稿与自定义阶段模板不自动改写。
新增实现：参考图模板与参考图＋首尾帧组合模板（3＋2 张图片）；镜头页选择工作流及各张图片 → 内置 MCP 上传图片 → ComfyUI 图生视频 → 保存与播放。资产图片生成仍为后续功能，当前仅保留统一图片导入接口。
界面保留原文、改写、分镜、提示词四工作区和左侧共享对话，导出为统一按钮。原文页仅提供文章输入、全文／选区和可选 Skill；已移除赛道、标题、受众、基调、人称、字数／时长及必需禁止内容表单，不提供按设定从零生成故事。
分镜页“复制分镜文本”输出视觉风格、场景概述、逐镜时间段、镜头要求、音频和限制，可直接整段粘贴。Markdown 导出使用此段落结构；格式示例见[交互设计](interaction.md#5-p-03-分镜)。
Agent Loop 默认首次生成后最多重试 2 次，检查仍未通过时输出最新候选供编辑；运行记录保留简明问题或失败原因，完整反馈进入应用日志，不新增检查报告。任务提示说明实际操作、对象和阶段，区分限流、超时、审阅／修订中断及部分完成。检查和有限修改在后台完成；左侧对话仅发送用户消息和聊天历史，已移除文档引用及说明；用户在右侧直接编辑并保存。不提供作用目标、应用修改、按意见修订或另存候选入口。

“提示词 → 镜头”的普通 H3 参考图支持“＋添加参考图片”，最多九个位置，空位自动跳过，至少选择一张；首尾帧工作流仍按模板固定输入。新增位置仅保留在当前工作流的内存草稿，生成只调整本轮图副本，不改写保存的 API JSON。

原文页 Skill 下拉框默认“不使用 Skill”，用户可明确选择项目内的 [短视频内容分镜 Skill](../../core/short_video/v2/skills/short-video-content-storyboard/SKILL.md)。只有选中后，分镜生成、检查和重试才共用冻结的 Skill；Agent 不自动选择，不向改写、资产或聊天注入。该 Skill 面向 MiniMax H3：常规5–8秒，必要短镜可低于5秒，超过8秒优先拆镜，控制单镜复杂度、声画容量和前后衔接，成片少于60秒。不使用 Skill 时基础提示和审阅不隐性套用 H3／5–8秒规则。旧项目缺少选择字段时同样不使用 Skill；旧配置与历史保留，不自动改写。仍未新增自动裁切或时长代码硬校验。

启动入口：项目虚拟环境运行 python main.py，首页切换到短视频脚本。顶部进入原文、改写、分镜、提示词，顶部“服务配置”包含原文字模型配置和 ComfyUI 工作流设置；文字设置仍复用第一部分配置窗口，导出为统一操作。
项目数据、文字服务、会话和导出能力继续复用；当前已接入本地 ComfyUI 视频，资产图片生成尚未接入；具体实现与限制见上述四份文档。文案与分镜保留历史版本；人物／场景／道具及镜头提示词仅保留当前一份，生成或保存时替换，取消提示词历史恢复和旧来源确认。不同对象、状态及视图仍分别保留。新流程不要求检查、确认或绑定操作；媒体任务另存实际输入快照，不恢复提示词历史 UI。

阅读顺序：先看架构中的总时序，再看 Agent Loop 内部流程；聊天单独看会话管理时序。普通聊天不会附加项目文档、不进入质量循环；默认 48,000 字符容量超限时裁剪最早完整历史轮次的请求副本，保留本轮消息与磁盘历史。

不设置总请求次数、整轮时限或 120 秒整次请求期限；网络超时由 SDK 管理。质量修改默认两次，格式错误最多修复两次，分别计数。合法候选在检查前保存，达到质量修改上限仍返回最新候选。资产设定与各视图由模型生成，镜头提示词由代码编排，优化镜头提示词时调用模型。

审阅按故事文案、视频文案、目录、分镜、资产与镜头提示词分别处理；总时长／有效目标偏差由代码计算并提供审阅线索，不作手动保存门槛。画面提示词编排去除完全重复描述，并明确固定设定是一致性约束，不要求所有细节同时入画。本次不增加 H3 视频提示词整理、自动出图或拼接。
