# 短视频脚本模式

保留小说功能，新增面向 AI 视频制作的中文独立剧情脚本：30–90 秒，默认 60 秒。第一版交付完整分场脚本，不生成视频、逐镜分镜或制作提示词。

## 使用

1. 小说首页点击「切换到短视频脚本」。
2. 在「创作需求」选择项目目录，填写创意、受众和限制并保存。
3. 生成大纲，编辑人物、冲突和故事节拍，点击「确认大纲」。
4. 生成完整脚本；自动进行整篇检查，必要时修订一次。
5. 查看版本和评审，可编辑、按意见再次修订、人工定稿并导出 Markdown。

新项目的需求页预填「雨夜借伞」验证示例：60 秒、最多 2 人、1 个地点，创意、受众、题材、基调、结尾、必需与禁止内容均已填写，可直接保存后测试生成。示例可编辑，已有项目仍加载自己的需求；预填不会自动保存或请求模型。

默认项目根目录为 `current_video_work`；所有数据位于该目录的 `short_video/`，与小说文件隔离。切换模式不自动请求模型。预计时长不等于真实成片时长；模型评审通过不等于人工定稿。

重启后，在「创作需求」填写原项目根目录并点击「打开项目目录」，即可恢复大纲、脚本版本和运行记录。模式页面位置和目录在当前会话内分别保留；重启不会自动恢复自定义目录或补发模型请求。自动修订预算不足时，可在脚本页填写意见后主动发起新修订任务。
