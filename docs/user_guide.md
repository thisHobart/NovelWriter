# 用户指南

更新日期：2026-11-03。当前桌面界面使用 PySide6，支持小说创作与短视频脚本两部分。

## 启动与模型

在项目虚拟环境中运行：

```powershell
python main.py
```

小说创作的侧栏和短视频工作台顶部均可打开“模型配置”。选择“第三方 API”后自行填写 OpenAI 兼容地址和密钥，点击“获取模型”查询后选择，也可手动输入模型名。获取列表不自动选择模型或保存配置；点击“保存配置”后用于后续生成与聊天。各服务商的地址、密钥和模型两边共用；用哪个服务商两边各自记住：小说跟着作品参数，短视频在顶部“服务配置 → 生成模型配置”里选，第一次打开短视频时沿用小说当时的选择。服务商、地址、密钥、模型列表查询及连接测试共用同一窗口，配置细节见[模型服务配置](API_CONFIGURATION.md)。

## 小说创作

1. 在作品参数中填写标题、输出目录、题材、篇幅与创作要求，保存参数。
2. 按“世界设定 → 故事结构 → 场景规划 → 章节撰写”生成和查看内容；也可在工作流页启动完整流程。
3. 在对应页面查看产物和状态。世界设定可[直接编辑保存](lore_editing.md)，后续生成使用保存后的内容。
4. 生成任务运行期间可停止。重新打开作品后，工作流依据磁盘产物与契约判定完成情况；“从断点继续”处理未完成阶段。
5. 章节未通过原有质量闸门时，在章节页面处理待复审内容；具体交互见[小说界面契约](UI_CONTRACT.md)。

## 短视频脚本

1. 从首页切换到短视频脚本。点左上角「新建项目」，选好目录后输入项目名称并保存。要继续已有项目，点「打开项目」并选择原目录。可以在「项目设置 → 重命名」修改左上角显示的名称，项目目录保持原样。
2. 在“原文”粘贴文章或导入 TXT／Markdown，选择全文或所选片段，填写赛道与创作要求并保存。
3. 生成小说推文，阅读后直接编辑；点击“用这版生成视频文案”，再用当前视频文案生成分镜。
4. 分镜表格用来浏览和排序（拖动行；右键可添加、拆分、合并、删除镜头）；选中一镜后，在表格下方的表单里改时长、取景范围、镜头运动、人物、动作、对白（含旁白）和音效，点“保存”写入项目。时长、顺序变化会重算时间轴；单镜常规 5–8 秒，短于 4 秒或超过 15 秒标红，整条片子要少于 60 秒。
5. 生成资产提示词，在人物／场景／道具／镜头标签中阅读、编辑或复制正负提示词。
6. 使用“导出”选择文案、分镜或提示词及保存位置，统一保存为 Markdown（.md）。

生成使用 Agent Loop：默认首次生成后最多再修改生成两次。检查仍未通过时展示最新候选，用户可以手动编辑；检查故障不会冒充通过，也不会被当作内容反馈反复生成。

左侧“与 AI 讨论”会附带右侧页面上现在的内容（包括未保存的修改）：原文页附带改编范围内的原文和创作要求，改写页附带当前稿子，分镜页附带整份分镜并以选中的镜头为重点，提示词页附带当前对象的设定和提示词，或当前镜头的视频提示词、参考图片和参数。输入框上方的标签写明附带了什么；点标签上的“×”改为普通聊天，点“+ 附带……”恢复，“查看附带内容”可以看这次会发给 AI 的全部内容。聊天回复不自动改稿；分镜页可以按回复里的镜头清单修改并应用到分镜，其他页面在右侧对应字段手动修改并保存。下一步会先保存可见编辑，保存失败不继续调用模型。

当前只生成文字及提示词，图片和视频由外部工具制作。完整规则见[短视频交互设计](short_video/interaction.md)。

## 保存与异常

项目保存在所选输出目录，路径见[项目文件](file_formats.md)。遇到保存冲突时保留编辑，核对当前版本后再处理。删除或移动作品前先停止任务；生成失败后按页面提示检查模型配置、网络或文件权限。
